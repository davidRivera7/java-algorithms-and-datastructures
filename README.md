## 🛠️ Dominios Técnicos y Módulos Principales

### 1. Estructuras de Datos desde Cero

Implementación propia de estructuras fundamentales sin depender de las librerías nativas de Java, optimizando la gestión de memoria y punteros:

* **Árboles Binarios y Árboles AVL:** Control de balanceo y rotaciones.
* **Grafos:** Representación flexible mediante **Listas de Adyacencia** y **Matrices de Adyacencia**.
* **Estructuras Lineales y Tablas:** Listas doblemente enlazadas (`DobleList`), Tablas Hash (`HashTable`), Pilas y Colas.

### 2. Paradigmas Algorítmicos y Backtracking

Soluciones optimizadas para problemas combinatorial y de búsqueda en espacio de estados:

* **Problema de la Mochila (*Knapsack Problem*):** Variantes de optimización (`Mochila`, `mochila2Best`).
* **Laberintos y Rutas Óptimas:** Resolución de caminos complejos mediante exploración exhaustiva.
* **Problemas de Combinatoria:** Variantes con dados, dardos, números y asignación de becas.

### 3. Algoritmos Destacados y Casos de Estudio

* **Rutas Más Cortas en Grafos con Backtracking:** Un desarrollo destacado que combina la potencia estructural de los grafos con algoritmos de búsqueda y retroceso para hallar caminos óptimos bajo restricciones específicas.

### 4. Resolución de Problemas y Práctica Constante

* **LeetCode Solutions:** Colección de problemas resueltos aplicando optimización de complejidad temporal ($O$) y espacial.
* **Divide y Vencerás:** Enfoques algorítmicos eficientes para reducir la complejidad de problemas grandes.
* **Interfaces Gráficas (GUI):** Aplicaciones de escritorio complementarias desarrolladas para visualizar o interactuar con la lógica de los algoritmos.
